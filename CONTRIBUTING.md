## Signing the Contributor License Agreement

Before your first contribution, open a separate pull request adding your GitHub ID to
[`.clabot`](.clabot). By doing so, you agree to the
[Contributor License Agreement](https://github.com/CommunitySpecification/1.0/blob/main/00-contributor-license-agreement.md). If you contribute on behalf of
your employer, make sure you are authorized to bind it.

A bot checks every pull request and blocks it until all its authors are listed in `.clabot`.
